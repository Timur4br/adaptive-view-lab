# Изменение проекта

Веб-интерфейс не использует внешних библиотек и сборки. Сохраняйте возможность открыть index.html напрямую и публиковать проект в подпапке GitHub Pages.

Перед изменением численной модели запустите npm test. После изменения повторите сверку с Python и объясните, почему потребовалось обновить контрольные значения. Увеличение допуска теста без объяснения расхождения не является исправлением.

Отделяйте интерактивные сессии от сохранённой сводки исследования. Истинные точки и опорная длина объекта не должны участвовать в выборе следующего действия. Будущие наблюдения становятся доступными оценивателю только на своём шаге.

Новые сценарии, отказы и отрицательные результаты сохраняйте вместе с параметрами. Преимущество перед слабым сравнением не заменяет проверку против хорошего первоначального плана и регулярной съёмки образца.

Для обсуждения изменения модели удобно указать сценарий, число генератора, стратегию и приложить экспорт сессии JSON.
