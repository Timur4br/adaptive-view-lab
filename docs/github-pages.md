# Как загрузить проект на GitHub

## Подготовка

Распакуйте архив. Корень проекта — папка, в которой находятся index.html, README.md и assets. Именно её содержимое нужно перенести в корень репозитория. Если положить всю папку ещё на один уровень глубже, указанный ниже путь публикации будет отличаться.

Лицензия пока не выбрана. При необходимости согласуйте условия распространения с соавторами и руководителем. GitHub-аккаунт и название репозитория в проекте не заданы.

## Загрузка через браузер

1. На GitHub создайте новый репозиторий, например adaptive-view-lab.
2. Выберите Add file, затем Upload files.
3. Загрузите содержимое папки проекта, сохранив вложенные каталоги. Убедитесь, что index.html находится в корне. Сам ZIP вместо распакованных файлов не подходит для запуска Pages.
4. Сохраните изменения кнопкой Commit changes.
5. Проверьте, что README показывает описание и снимок интерфейса.

Веб-загрузка может не включить скрытые файлы автоматически. Для самого сайта нужны index.html и assets; для полного проекта также сохраните .github, .gitignore и .nojekyll. GitHub Desktop переносит эту структуру удобнее.

## Включение GitHub Pages

1. В репозитории откройте Settings, затем Pages.
2. В Build and deployment выберите Deploy from a branch.
3. Выберите ветку с проектом, обычно main, и папку /(root).
4. Нажмите Save и дождитесь завершения публикации.
5. Откройте адрес, который GitHub покажет на странице Pages.

Не угадывайте адрес сайта: используйте фактически выданную ссылку. Все пути ресурсов в проекте относительные, поэтому сайт поддерживает публикацию в подпапке репозитория.

[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) описывает выбор ветки и папки публикации. Доступность Pages зависит от типа репозитория и тарифа аккаунта.

## Автоматические проверки

В .github/workflows/tests.yml подготовлен workflow для численных тестов JavaScript и коротких проверок Python. Он не публикует сайт и не изменяет содержимое репозитория. После загрузки посмотрите результат во вкладке Actions. До загрузки выполнены только локальные проверки.

## Изменения модели

Нельзя обновлять рисунки и численные выводы вручную так, чтобы они расходились с сохранёнными данными. Новый вычислительный запуск сохраняйте в отдельную папку, затем обновляйте сводку экспортом и повторяйте тесты. Описание параметров и ограничения сохраняйте вместе с результатами.
